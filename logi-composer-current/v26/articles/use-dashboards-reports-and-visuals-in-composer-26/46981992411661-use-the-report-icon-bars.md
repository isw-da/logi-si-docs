# Use the Report Icon Bars

When you create or edit a report, a series of icons are available you can use to perform specific report functions.

![view a report as a non-editor](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527882924941 "report options icons ")

![options available for reports for exporting, refreshing, deleting, saving, and more](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527875495437 "report icons bar")

Select an icon to perform the function described in the following table.

**Note:** 
The visibility of these icons on a report are affected by interactivity settings defined for dashboards in the library. See [Control How Users Interact With a Dashboard](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701076696717-Control-How-Users-Interact-With-a-Dashboard).

| Icon | Description |
| --- | --- |
| toggle between view and edit mode | Toggle view mode between Viewer and Editor modes. |
| export this item | Export a report. Enabled if there are no unsaved changes to your report.  Select to open a preview window of your report; review and export or cancel the export. See [Export Your Self Service Report](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/46982018753165-Create-Self-Service-Reports#Export). |
| select to share your self service report | Share your report. |
|  | Refresh the data in the report. |
|  | Mark the report as a favorite. |
| select to enable or disable header and footer | Select to enable and disable the header and footer. See [Edit the header and footer in a self service report](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/46982032879373-Edit-and-Delete-a-Self-Service-Report#header). |
| create a schedule for the self service report | Schedule a self service report to be sent. See [Schedule a Self Service Report or Dashboard Report](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701093791245-Schedule-a-Self-Service-Report-or-Dashboard-Report). |
| delete the report | Delete the report. See [Edit and Delete a Self Service Report](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/46982032879373-Edit-and-Delete-a-Self-Service-Report). |
| save your item with a new name | Save a report with a new name (which copies it). |
| save your item | Save a report. |
