# Zoom Into a Time Bar Range

**Zoom into a time bar range**

1. Select a visual on the dashboard.
2. Select a time range for the time bar. See [Adjust the Time Bar Range](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701166967181-Adjust-the-Time-Bar-Range).
3. Select zoom tool icon ![](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48528038174733) on the right side of the time bar to zoom into the selected range. Only the times for the time range you selected are shown on the time bar.

   To view all the available times in the data, select the all icon ![](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527894007565) on the time bar. To select the maximum range of values, select the maximize icon ![](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527896374413) on the time bar.
4. Save the dashboard.
