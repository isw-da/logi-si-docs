# List Dashboards

**Note:** In this release, when your admin enables the Enhanced Experience user interface, you will see changes to workflows you may have used in previous releases.

**List the dashboards in a** Composer **instance**

1. Log into Composer as an administrator or a user who has been assigned to a group with the [**Administer Dashboards** privilege](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701005611789-Group-Privilege-Reference).
2. Select the **Discovery Board** card on your home page or **Library** from the main menu. The dashboard library opens.
