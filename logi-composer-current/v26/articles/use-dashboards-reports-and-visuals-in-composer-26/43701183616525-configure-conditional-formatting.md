# Configure Conditional Formatting

Format your tabular visuals and self service reports by adding color and text formats based on the conditions you define. The [Conditional Formatting sidebar](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701169433997-Use-the-Conditional-Formatting-Sidebar) allows you to set formatting based on conditions to apply to your data.

## Define Conditional Formatting for Table Visuals

1. Select a table visual in a dashboard, a self service report, or the Visual Gallery.
2. Select the conditional formatting icon ![](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527866929293) in the sidebar menu. The Conditional Formatting sidebar opens.

   ![Add conditional formatting rules here](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527871224717 "Conditional Formatting Work Area")
3. Select **Add** to open the add rule work area. Use this work area to define a condition and the formatting to apply.

   ![define conditions and formatting to apply to tables](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527871262093 "Add or Edit Conditional Formatting - tables")
4. Select the add icon ![add icon](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48528024188813 "add icon") in **Select When To Apply Formatting** to define the conditions to apply your formatting. See [Using the Conditional Formatting Sidebar - Tables](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701169376269-Using-the-Conditional-Formatting-Sidebar-Tables).

   ![Select an attribute to define a condition](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527828250765 "Attribute Selection work area")

   Select a row or group attribute. The Value work area opens. Define the values for this condition. See [Use the Conditional Formatting Sidebar](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701169433997-Use-the-Conditional-Formatting-Sidebar).

   ![Select the values formatting will apply to here](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527871356813 "Select values for an attribute work area")

   Select **Continue** to save your changes and define the formatting options.
5. Optionally, enable **Format entire row** in **Select Where To Apply Formatting** to format the entire row. Disable to format only the applicable cell.
6. Select the add icon ![add icon](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48528024188813 "add icon") for **Formatting** to define the formatting to apply to data that matches the condition you set. See [Use the Conditional Formatting Sidebar](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701169433997-Use-the-Conditional-Formatting-Sidebar).

   ![define the formatting to apply to your selected attribute](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527856998413 "Format Rule Work Area")

   Select a formatting option and define the look you need. See [Use the Conditional Formatting Sidebar](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701169433997-Use-the-Conditional-Formatting-Sidebar).
7. Optionally, add as many formatting options as you need. Formats are applied sequentially: see [How Composer Applies Formatting Rules](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701212929165-How-Composer-Applies-Formatting-Rules). Select the delete icon ![](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527871438477) to remove any unneeded options. Select **Continue** to save your changes.
8. Optionally, add more conditional formatting rules. Drag and drop the rules change their order. In a case where multiple formatting rules apply to results of overlapping conditions, formats are applied sequentially. See [Use the Conditional Formatting Sidebar](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701169433997-Use-the-Conditional-Formatting-Sidebar).

   ![add, remove, or edit rules as needed](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527828404749 "Conditional Formatting work area")
9. Select **Apply** to apply your changes to the visual.

## Define Conditional Formatting for a Pivot Table Visual

1. Select a table visual in a dashboard or in the Visual Gallery.
2. Select the conditional formatting icon ![](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527866929293) in the sidebar menu. The Conditional Formatting sidebar opens.

   ![Add conditional formatting rules here](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527867152397 "Conditional Formatting Work Area")
3. Select **Add** to open the add rule work area. Use this work area to define a condition and the formatting to apply.

   ![define conditions and formatting to apply to pivot tables](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527842852749 "Add or Edit Conditional Formatting - pivot tables")
4. Select the add icon ![add icon](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48528024188813 "add icon") in **Select When To Apply Formatting** to define the conditions to apply your formatting. See [Using the Conditional Formatting Sidebar - Pivot Tables](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701131208717-Using-the-Conditional-Formatting-Sidebar-Pivot-Tables).

   ![Select an attribute to define a condition](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527828498957 "Attribute Selection work area")
