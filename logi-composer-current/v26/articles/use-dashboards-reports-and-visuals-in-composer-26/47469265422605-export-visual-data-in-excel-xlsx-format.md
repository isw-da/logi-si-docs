# Export Visual Data in Excel (XLSX) Format

When you [enable](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701053868173-Server-Level-Variables#self-srv-rpt-ssa) self service report [microservice](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/47077282029965-Self-Service-Report-Microservice) in your environment, users can export self service reports and table visuals, complete with formatting and conditional formatting, to a formatted Excel (XLSX) file format.

## Export a Visual as XLSX With Formatting

Table visuals can export to Excel (XLSX) files with formatting and conditional formatting when the [report service](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701053868173-Server-Level-Variables) is [enabled](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/47077282029965-Self-Service-Report-Microservice).

1. Select **Export** from the [visual drop-down menu](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701184743565-Use-the-Visual-Drop-Down-Menu). Select the export option **XLSX With Formatting**.
2. The Export as XLSX dialog opens.

   ![Rename your file and add or remove the time bar using this work area](https://logi-composer-v26.insightsoftware.com/hc/article_attachments/48527853609869 "Export as XLSX  work area")
3. Accept or change the file name.
4. Select **Export**. Logi Composer prepares an Excel (XLSX) file downloaded by your browser.
