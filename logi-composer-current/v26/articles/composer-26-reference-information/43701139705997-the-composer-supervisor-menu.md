# The Composer Supervisor Menu

# The Composer Supervisor Menu

When you log in as a user that belongs to the Supervisors group, you have default access to more options than are in the [main menu](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701160499853-The-Main-Menu) for other users. The supplied [admin user](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701036219149-Supplied-Users-and-User-Groups#The2) and other system administrators are members of the Supervisors group.

**Note:** 
The default **supervisor** user is no longer installed; add users to the **Supervisors** group instead.
