# The Main  Menu

# The Main Menu

The main navigation menus are located on the left side of Composer. The menu options you see are dependent on your application privileges and licensed features.

**Note:** In this release, when your admin enables the Enhanced Experience user interface, you will see changes to workflows you may have used in previous releases. If you are running an earlier release or your admin has not enabled the new interface, see [UI Menu (Earlier Releases)](#v26.2).

## Main Menu Options for All Users

All users' menus include:

* An expand and collapse option. Expand and collapse the menu by selecting the expand or collapse icon at the top of the menu.
* A **Data Sources** option. Select this icon to navigate to the [Data Sources work area](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701081381901-Data-Sources-Page).
* A **Visual Gallery** option. Select this icon to navigate to the [Visual Gallery work area](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701180261773-Use-the-Visual-Gallery).
* A **Library** option. Select this icon to navigate to the [Dashboard Library](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701047640717-Use-the-Library-for-Dashboards), and when enabled, the [Reports Library](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/46982003574285-Use-the-Self-Service-Reports-Library).
* **Help** icon. Select to open product help, access [Technical Support](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701072313613-Contact-Technical-Support), or view information [about](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701106879757-About-Dialog) your environment.
* **Profile** icon. Select to open the profile menu. View your user information, switch between tenants if you are a member of more than one tenant, or log out.

## All Main Menu Options

The menu options you see are dependent on your application privileges and licensed features. Administrators, members of the Supervisors group, and the specific [privileges](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701005611789-Group-Privilege-Reference) your administrator defines for you determine what you can see, access, or manage.

In environments where the [enhanced-experience](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701053868173-Server-Level-Variables#ui-toggle "enhanced-experience link") toggle has been enabled, the menu option **System Users** has been removed from the main menu UI. Users with appropriate privileges can instead access users using the **User** menu option, and groups using the **Groups** menu option.

## UI Menu (Earlier Releases)

Navigate to the user interface (UI) menu by selecting the menu icon in the upper right corner your software. Menu options vary: users who are members of the Supervisors or Administrators group, and users with specific group [privileges](https://logi-composer-v26.insightsoftware.com/hc/en-us/articles/43701005611789-Group-Privilege-Reference) have access to different options.

The table below describes menu options available to user groups in Composer in v23.4 and later.

**Note:** 
The default **supervisor** user is no longer installed; add users to the **Supervisors** group instead.
