# Generate Visuals

<Note>
  This feature is no longer in beta and can be used in production environments.
</Note>

<Warning>
  You must have the appropriate licensing from insightsoftware to see this option.
</Warning>

If you have integrated Simba Agentic Intelligence into your environment, you can use AI to generate visuals quickly.

Select **Generate Visuals with AI** from the [main menu](/simba-embedded-analytics/docs/self-service-analytics/26.3/get-started/access#the-main-menu) or your [home page](/simba-embedded-analytics/docs/self-service-analytics/26.3/get-started/access#home-page).

Enter a natural language prompt into the AI Visual Generator with information you would like to generate a visual for.

The system reads column names and descriptions to intelligently gather and structure your data to the type of visual you would like to create, or prompt you to select a visual type if you do not specify one.

Example prompts:

* Create a chart of last year's sales
* Make a pie visual showing me sales by region
* Build me a word cloud of visitors by country of origin

After your visual is generated, you can save it to the [Visual Gallery](/simba-embedded-analytics/docs/self-service-analytics/26.3/analyze-data/visuals/visual-gallery), edit it, or discard it as needed. A default name is defined for your visual, but you can rename it at any time. Add to a dashboard or report once saved in the gallery.

<Note>
  If your request does not specify an item needed to generate the visual, for example, a specific source or field, you may be prompted to adjust your request.
</Note>
