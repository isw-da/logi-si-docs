# Manipulate Data in the Data Store

Self-Service Analytics allows you to manipulate the data read from your data store. You can enable distinct counts and Data Sharpening, change the formatting of numeric and time fields, convert appropriate existing data store fields into time fields, and use existing data store fields to create derived fields and custom metrics.
