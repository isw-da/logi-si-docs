# What of 26.3 is public, and how stale that makes this mirror

Checked 29 September 2026 against non-Atlassian, publicly reachable sources only. This file
answers the question this repository exists to answer: on the day it was checked, how far
behind upstream is the mirror, and where exactly is the gap.

Read it before assuming a missing page is a capture failure. For Simba Agentic Intelligence
26.3 there is nothing upstream to capture.

## Simba Agentic Intelligence 26.3: nothing is public

| Check | Result |
|---|---|
| `insightsoftware.mintlify.app/simba-agentic-intelligence/docs/26.3/...` | **HTTP 404**, as do `/docs/26.3` and `/docs/26.3/release-notes` |
| Live `llms.txt` | 27 Agentic Intelligence pages, **every one under 26.2** |
| Sitemap | 27 agentic URLs, **zero** at 26.3 |
| Public release notes | top out at **26.2 (June 2026)** |
| Logi Composer v26 Zendesk help centre | all 883 articles pulled, **zero** occurrences of "26.3"; newest is the 26.2 release notes, everything last updated 31 August 2026 |
| `insightsoftware.com/simba` | names the module, carries no version |
| Four web searches for a 26.3 announcement | nothing |

The most recent public press is the three-brand launch of 16 September 2026, which names no
version.

Consequence for this mirror: `simba-intelligence/pages/` cannot be refreshed to 26.3, because
there is no 26.3 upstream to refresh from. The 26.2 pages are not stale relative to upstream;
they are stale relative to the product. Corrections live in `26.3-authoritative.md` in this
directory.

## Composer / Self-Service Analytics 26.3: yes, substantively

**176 public pages** at
<https://insightsoftware.mintlify.app/simba-embedded-analytics/docs/self-service-analytics/26.3/>

Two things about them:

- The 26.3 release-notes page is an **empty stub** ("Watch this page for updates..."), so the
  absence of release notes is not evidence that nothing changed.
- Other pages carry real version-specific content. The Kubernetes install page states
  verbatim that "Kubernetes is supported for new installations only for version 26.3 and
  later", with Helm chart `composer/composer`. That matters to Simba Agentic Intelligence,
  which deploys on Kubernetes and which ships inside the Composer chart from 26.3 (PY-693).

**None of the Agentic Intelligence feature set appears in those 176 pages.** Filtering the
whole 26.3 index for `ai`, `ask`, `nlq`, `natural`, `prompt`, `assist`, `smart` and
`intellig` returned zero pages.

## The most recent public 26.3 mention, and why it is only a lower bound

**28 September 2026**, taken from the documentation sitemap.

**Caveat, and it is load-bearing:** every 26.3 URL in that sitemap carries the same timestamp
to the millisecond. That dates the **site build, not the authoring** of any page. Treat
28 September 2026 as a hard lower bound on when the Composer 26.3 documentation existed, and
not as evidence about any individual page. No Wayback Machine snapshots of the Mintlify host
exist, so there is no independent way to date it more precisely.

## One adjacent public fact that clears an external blocker

Microsoft documents six Claude models as generally available on Azure AI Foundry, updated
22 September 2026, with the endpoint
`https://<resource>.services.ai.azure.com/anthropic/v1/messages` and an `anthropic-version`
header:
<https://learn.microsoft.com/en-us/azure/ai-foundry/concepts/models-sold-directly-by-azure>

This corroborates, from outside insightsoftware, that the configuration is the Anthropic
shape rather than the Azure OpenAI shape. See section 6 of `26.3-authoritative.md`.

What it does not show: the public Simba Agentic Intelligence 26.2 LLM provider guide
documents exactly three providers (Google Vertex AI, Azure OpenAI, AWS Bedrock), with Claude
only under Bedrock. Azure AI Foundry is not named anywhere public. So the public baseline
still contradicts the 26.3 position, and there is no public evidence either way that
insightsoftware has shipped it. The platform capability being GA means nothing outside
insightsoftware blocks it.
